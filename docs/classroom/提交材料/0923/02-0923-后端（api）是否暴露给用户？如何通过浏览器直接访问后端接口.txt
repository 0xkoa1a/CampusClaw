后端 API 可以通过浏览器访问，但默认只映射到服务器本机的回环地址。

Flask 同时提供网页和 /api/ 接口。Dockerfile 使用 Gunicorn 在容器内的 0.0.0.0:8080 监听；docker-compose.yml 将应用端口映射为 127.0.0.1:8080:8080。因此，服务器本机可以访问网页和 API，远程电脑可以通过 SSH 隧道访问。这个端口映射不允许外部机器直接连接服务器的 8080 端口。Qdrant 没有映射宿主机端口，仅供容器网络内的应用访问。

Dockerfile 中的 EXPOSE 8080 是镜像端口声明，实际能否从宿主机访问由 Compose 的 ports 设置决定。网页与 API 使用同一个 Flask 服务和端口。

浏览器登录后，在同一网站地址后添加 /api/materials，即可直接查看本班材料的 JSON 响应。浏览器会自动携带登录 Cookie，后端据此识别用户。配图展示的地址为 http://127.0.0.1:18081/api/materials，请求成功返回 200；18081 是取图环境的本地访问端口。

同样可以直接访问 /api/me 查看当前用户身份，访问 /health 查看服务健康状态。未登录访问受保护的 API 返回 401。

地址栏直接访问发送的是 GET 请求。登录、上传和问答等 POST 请求由网页表单、前端脚本或 API 客户端发送；自定义 Authorization 请求头也需要通过脚本或客户端设置。
