2先记住三条结论

提示词挂在智能体上，不再每班一份

智能体存于 tutor_agents，字段含名称、角色提示词与启用状态，每班可以有多个，由教师创建与维护。角色提示词为空的智能体回退到默认角色设定（fallback），不因此拒绝请求。班级提示词表 class_prompts 保留，但回答路径不再读它。

一次提问只选至多一个技能

候选集是该智能体绑定且已启用的技能；未绑定的技能即使适用条件命中，也不参与路由。路由在候选集里按适用条件做词法命中计分（lexical scoring），取最高分的一条；同分取技能编号较小者；零命中即不选技能。命中的技能名称含「解题引导」时，回答不得写出最终答案、选项、得数或完整解题过程。

检索优先，落空仍作答

有超过相似度下限的命中时，回答优先依据这些材料，并用 [n] 标出出处。检索落空、或该智能体没有绑定材料时，不再用固定文案结束：仍按该智能体的提示词作答，引用列表为空数组，回答里不出现编号，也不得编造出处。
