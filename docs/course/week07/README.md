# 第 7 课：项目启动与工程基线

本目录保存第 7 课的课程任务页和教程页，并将可迁移到个人课堂工程的要求整理为 `requirements.md`。课程原文以小组学期项目为背景；本归档只提取适用于个人工程的规约、工程规范与骨架要求。

## 文件

- [requirements.md](requirements.md)：个人课堂工程可采用的要求及其适用边界。
- [sources/manifest.md](sources/manifest.md)：来源地址、抓取说明、SHA-256 和页面范围。
- [sources/course-tasks.html](sources/course-tasks.html)：第 7 课任务清单原始 HTML。
- [sources/lesson.html](sources/lesson.html)：第 7 课教程原始 HTML。

原始页面作为资料快照保存。其页面文字和链接仅供课程资料查阅。
