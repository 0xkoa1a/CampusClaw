# 后端开发规范

## Flask 与 API

- Flask blueprint 负责路由、HTTP 状态码和输入解析；可复用业务流程放在对应模块函数中。路由不得把外部网络调用藏进 SQLite 事务。
- JSON API 使用 `/api/<资源>` 命名；查询用 GET，创建用 POST。成功响应字段稳定并写入 OpenAPI；错误响应给出简短原因，不返回异常堆栈。
- 状态码统一判据：格式或范围错误 400，未登录 401，已登录但角色不符 403，跨班/他人资源与不存在资源均 404，幂等键对应不同正文 409，依赖不可用 503。
- 所有请求先验证 JSON 对象、必填字段、类型、长度、数值边界及枚举白名单；非法筛选明确返回 400，不降级为无筛选全量查询。
- 列表排序必须有唯一兜底键；分页上限固定并校验，不能让用户参数触发无界读取。

## SQLite 与资源访问

- SQL 值一律使用 `?` 参数绑定；表名、列名、排序方向只能从服务端白名单选择。
- 写操作用 SQLite 事务上下文或显式 BEGIN/COMMIT/ROLLBACK。异常时整笔回滚；读接口保持只读，不在轮询中创建任务或触发模型调用。
- 异步提交将提交记录、任务和 outbox 记录写入同一事务；结果、任务终态与执行次数按规约原子更新。任何 LLM、MCP、Qdrant、RabbitMQ 网络调用都在数据库事务之外。
- SQLite 迁移可重复执行，不删除既有作业或资料；迁移失败不得留下半套表结构。关联字段声明外键或有等效完整性检查。
- 每次按资源读取或修改时，把资源 ID 与会话中的班级/用户条件放在同一条查询或更新中；不能先按 ID 取出再漏做归属检查。

## 外部服务与异步任务

- Qdrant 查询必须带服务端确定的 `class_id` 过滤；MCP URL、令牌和工具授权来自服务端配置，不能由模型或学生参数覆盖。
- 第 8 课规约选用 RabbitMQ + pika：持久队列和持久消息、发布确认、手动 ACK、`prefetch=1`、至少一次投递；只有结果事务提交后才 ACK。实现与真实代理验收分别记录，不能以源码存在替代验收。
- outbox 投递与消费者执行可重复。以数据库唯一约束和租约/条件更新控制结果只生效一次；不得声称外部模型调用只发生一次。
- 外部调用设置超时，错误转换为稳定的服务错误或任务失败状态；日志保留任务标识和安全错误类别，不记录密钥或完整敏感正文。
