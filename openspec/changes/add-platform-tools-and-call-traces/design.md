# 设计

复用智能体作为 AI 应用，角色提示词作为模板实例；工具来自命中技能的声明与教师显式绑定。第六课采用同仓 `mcp-server/` HTTP 服务，由 Compose 与主应用一起启动，至少两个工具。教师登记本班服务器，使用管理员环境变量中的令牌连接、发现、断开及审计。Base URL 必须在管理员允许列表中。

普通会话直接请求流式模型。绑定工具的会话先使用非流式 function calling，最多两轮、累计四次调用、总计30秒；触顶后基于已有结果生成最终流式回答。MCP 使用 `POST /mcp` JSON-RPC 2.0，执行 initialize、initialized、tools/list、tools/call；Bearer 令牌仅在服务端出站头中使用。工具声明与参数 JSON Schema 来自发现缓存，使用同一 schema 校验。技能支持 `工具名@服务器名`，保存时与每次执行前均检查班级、连接及缓存。调用失败回传固定错误数据，继续回答；meta 中按顺序列出实际调用及状态。工具返回按不可信数据处理，已知指令式句式替换为固定提示。

知识库始终在班级和绑定材料范围内检索，只将前四个非空切片加入当前消息。仅命中且启用的绑定技能正文进入 system；原始上传文件和其余技能不整体拼接。技能描述不作为 Python 或 shell 代码执行。

记录从实际网关发送点采集，保留请求体与每个上游 SSE 数据帧；HTTP Authorization、Cookie 和环境变量不采集。记录挂到单轮用户消息，归属校验与会话相同，删除会话级联清除。教师另有本班工具调用审计，不允许读取他人完整模型上下文。验证资料使用合成内容，正式私有记录不导出入 Git。失败和断连也保存已采集数据与状态。

迁移仅新增表和智能体工具列，旧智能体默认为无工具。数据库事务不跨越模型及外部进程调用。
