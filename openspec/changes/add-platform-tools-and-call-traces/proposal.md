# AI 应用平台与调用验证

## 目的

在现有智能体、提示词、技能和知识库之上接入外部工具与 MCP，记录每轮真实模型请求及返回。用合成资料验证提示词、知识切片、命中技能和工具结果如何进入模型上下文，形成附 Git 地址与项目介绍的 PDF 报告。

## 范围

- 教师选择提示词模板、导入技能并配置智能体可用工具；学生在本班应用中对话。
- 通过服务端允许的工具执行有界计算；通过独立 MCP 进程发现及调用工具。
- 模型使用标准 function tools 协议选择工具，工具结果回传模型后生成最终回答。
- 每轮保存请求 JSON、上游返回和工具调用记录；仅会话所有者可读取。
- 保留既有登录、检索、技能路由与流式响应行为。

## 交付

课程来源归档、逐项实现计划、OpenSpec Scenario、代码与测试、真实合成场景记录、截图，以及集中存放的 Markdown/HTML/PDF 报告。
