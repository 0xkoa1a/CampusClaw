## ADDED Requirements

### Requirement: 教师配置本班智能体与技能
系统 MUST 支持教师管理本班智能体、中文字段技能文件及本班技能/材料绑定；学生 MUST NOT 执行写操作。技能文件 MUST 校验课程规定的字段、长度及唯一名称，工具仅支持 knowledge_search。旧数据迁移 MUST 保留 ID、身份和材料，旧技能默认禁用。

#### Scenario: 配置与迁移
- **WHEN** 教师提交有效技能文件并绑定本班资源，随后重复迁移
- **THEN** 配置 MUST 保留且 MUST NOT 重复生成，旧材料与账号 MUST 不变
- **AND** 重名、超长、未知工具或重复字段 MUST 返回 400；跨班绑定 MUST 返回 404 且原绑定不变

#### Scenario: 服务端写权限
- **WHEN** 学生伪造教师角色请求写技能或智能体
- **THEN** 系统 MUST 返回 403，且 MUST NOT 改变数据

### Requirement: 按当前配置路由与限定检索
系统 MUST 在绑定且启用技能内词法计分，最高分为零不选，同分取较小 ID；每轮重读配置。检索 MUST 在查询阶段限制本班绑定材料，取混合排序前四条后过滤学科和空正文。

#### Scenario: 技能停用与未绑定高分材料
- **WHEN** 当前会话技能被停用或解绑，且有高相关未绑定资料
- **THEN** 下一轮 MUST 不选择该技能、MUST 不引用未绑定或跨班资料

#### Scenario: 智能体开关
- **WHEN** 本班智能体被停用
- **THEN** 学生 MUST 不可用其新建会话，已有会话 MUST 仍可继续提问
