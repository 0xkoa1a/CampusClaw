# Proposal

## Why

CampusClaw 面向校园教学材料管理。材料分散在群文件与网盘中，学生难以查找，班级之间也缺少数据边界。本变更先建立身份、角色与班级隔离，让教师登录后上传并管理本班材料，学生只能查看本班内容，为后续检索与助手能力提供基础。

## What Changes

- **用户登录**：教师和学生使用账号密码登录；未登录用户访问受保护页面时跳转到登录页。
- **角色权限**：教师可以上传和管理本班材料；学生对本班材料只读；学生调用上传接口时返回 HTTP 403。
- **班级隔离**：班级作为数据边界；所有业务查询在服务端按会话中的班级过滤；A 班用户无法读取 B 班材料。
- **材料上传与知识库入库**：教师上传后，系统保存文件、解析文本并写入知识库；本班材料列表从数据库读取，上传成功后可以看到新记录。
- **预置样本数据**：建立班级、用户、讲义、作业、助手、技能六类核心数据结构，预置班级 A/B、教师 A、学生 A1/B1 和两班可区分的样本材料。
- **安全与运行**：密码使用单向哈希存储；会话密钥只从服务端环境变量读取；标准启动方式为 Docker Compose；应用提供 `GET /health`。
- **文档**：README 说明产品价值、核心场景和本学期范围；Apply 阶段补充 Docker 启动方式、`.env.example` 和运行地址。

## Capabilities

### New Capabilities

- `auth-upload`：登录与会话、按角色授权、按班级隔离、教师上传材料入库、预置数据、密码与密钥安全、Docker Compose 和健康检查。

### Modified Capabilities

无。当前 `openspec/specs/` 中没有已有主规格。

## Impact

- Apply 阶段将新增登录页、材料列表、教师上传接口和健康检查接口。
- 将新增 SQLite 持久层、初始化脚本和双班样本数据。
- 将新增 Flask 应用、依赖清单、Dockerfile、Docker Compose 配置和环境变量示例。
- 本 change 只交付规约，具体实现留到后续 Apply 阶段。

## Non-goals

- 不实现 RAG、全文检索、智能问答或知识库对话。
- 不实现聊天界面、智能体编排或技能运行时。
- 不实现作业提交、批改、成绩、审计或错题本。
- 不实现注册、找回密码、OAuth/OIDC、SSO、短信或邮箱验证码登录。
- 不实现多校区、多租户、Kubernetes、多副本高可用或完整 CI/CD。
- 不使用前端隐藏按钮替代服务端权限检查和班级隔离。
