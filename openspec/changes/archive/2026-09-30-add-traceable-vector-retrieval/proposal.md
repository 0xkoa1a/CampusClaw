# Why

第三课已能保存本班材料全文，但学生无法按问题定位相关片段，也无法核查回答依据。第四课要求在已有登录与班级边界上增加可追溯检索。

# What Changes

- 从原文生成可重建的切片与关键词索引，在 SQLite 保存正文、来源和位置。
- 在私有 Qdrant 中保存对应切片的向量与最小标识，接入课程网关的向量和对话接口。
- 提供关键词、向量、混合检索及带引用的简短回答；无依据时明确告知用户。
- 为教师提供重建索引入口，并处理网关或 Qdrant 故障而不丢失原始材料。

# Impact

沿用第三课的 Flask、SQLite、会话及上传接口。新增可迁移的数据表、Qdrant 服务、私有模型配置、检索接口和材料页交互。第五课的流式对话与长会话不属于本次变更。
