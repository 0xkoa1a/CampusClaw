# 设计与实施计划

- 保留现有服务端角色、班级和资源归属检查；为Cookie写请求加入同源校验，Bearer仍由服务端会话确认权限。
- 资料、技能正文和学生答案不拥有系统指令权限；集中检测显式注入，资料留作数据、危险片段拒绝进入生成上下文，错误不泄露提示词。
- HTTP结构化日志记录服务器生成的request_id、身份、耗时和状态；不记录请求正文和凭据。MCP审计增量迁移补耗时和request_id；模型用量单独记录，未知用量不能伪造为零。
- 新增make check-security、CI测试/安全门禁及推送构建工作流；固定依赖并复核审计，镜像携带commit标识。
- 安全反例与红绿门禁使用隔离合成环境；压测固定参数并保存原始采样。远端变更在本地测试完成后执行；不复制现有私密.env备份。
