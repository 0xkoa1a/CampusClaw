# 设计

工具原始结果先做指令式内容检查，再对允许进入模型的文本截断；默认最多4000字，截断附固定标记。原始网关/MCP记录与送入模型的有界结果保持分开，引用编号与会话持久化继续沿用现有实现。

新增可调 MCP_MAX_ROUNDS（默认2）、MCP_MAX_CALLS（默认4）、MCP_TOOL_TEXT_MAX_CHARS（默认4000），均在启动时验证。调用上限达到后继续生成回答，不额外执行工具。

写审计前按当前班级、服务器名称与预期编号重新确认归属。服务器不存在、改名或调用期间删除时不写独立审计，但应答的tool_calls仍保留denied/error。已有服务器断开时仍写denied。审计写入不新增修改或删除接口。

验证使用独立合成环境；受控模型替身只用于确定性错误、配额和长文本边界，并在证据中标注，不冒充真实网关。第七、八课另建规约，不能把安全自查提前变成第九课修复。
