# Review 02：AI 七类代码审阅

审阅方式：AI 对当前变更及对应测试进行七类检查，并与本地安全、门禁和 HTTP 证据交叉核对。本记录属于 AI 自审，不是组员独立复现，也不代表远端 CI 结果。

| 类别 | 检查内容与判据 | 结果 |
| --- | --- | --- |
| 接口入口 | 检查登录、角色、来源与 CSRF 约束，以及请求方法/响应码；用例判据为未授权请求不进入写逻辑。 | 本地 401/403/400 检查通过；修复过程中出现的 CSRF API 误拦已回归复测。 |
| 业务逻辑 | 检查提交返回 202、教师评分覆盖、学生不可写、跨班任务不可见和提示词显式 guard。 | 本地 HTTP JSON 对应判据全绿；未据此声称真实模型行为通过。 |
| 数据库 | 检查 SQLite 表约束、事务写入与列表查询索引对照；判据为记录可持久化、越权记录不可见、同参数前后查询可比较。 | 20,001 行本地任务数据用于查询基准；没有迁移或验证 MySQL。 |
| 公共函数 | 检查请求审计序列化、空值、技能选择和查询过滤的边界；判据为 JSON 字段合法、`skill=None` 可表示且查询范围来自服务端身份。 | 空技能值和观测用例通过；该空值问题在修复过程中曾出现，耗时未记录。 |
| 错误处理 | 检查缺少认证、权限不足、跨班对象、无效请求和流式错误的状态码与落库副作用。 | 对应本地 401/403/404/400 检查和流式用例通过；未声称覆盖全部部署故障。 |
| 安全 | 检查 SQL 注入、XSS 输出转义、CSRF、越权写入、提示词 guard、日志脱敏与密钥扫描。 | HTTP 判据通过；XSS DOM 单独确认已转义；scanner 为 0。SEC-08 真实模型实验仍待办。 |
| 性能 | 检查同一任务列表查询在相同请求体、并发和请求数下的索引前后差异，并查看并发 1/4/8 的提交、查询、检索样本。 | 本地 SQLite 样本无失败；结果与局限见 [`report.md`](../report.md)。样本不代表 MySQL 或生产容量。 |

复核边界：本审阅依赖当前工作区代码、自动化用例和 `reports/week10-local/` 数据。没有检查远端部署状态、CLab/真实模型实验或 GitHub 分支保护配置。
